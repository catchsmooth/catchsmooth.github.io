## 先选你习惯的工作方式

如果希望围绕编辑器理解和修改项目，可以先阅读 Cursor 的入门文档。偏好终端则从 Claude Code 的概览了解工作方式。已经使用 GitHub 的开发流程，可以先了解 Copilot；Codex 官方学习入口则提供代码开发与审查相关资料。

这些工具的工作方式有交集，不必一次全部安装。先选择一个能放进现有流程的入口。

## 按这个顺序阅读

1. 阅读所选工具的官方概览，确认支持的开发环境与使用方式。
2. 查看它如何理解项目上下文、接收任务并展示修改。
3. 再阅读规则、权限与改动审查的说明，明确哪些操作需要人工判断。

## 用一个小任务建立判断

可以选择解释一个模块、修复一处明确的问题，或者补充一段文档。给出目标、相关文件与验收条件，再检查它提供的差异与验证结果。这是学习建议，不是本站的产品实测或性能比较。

## 继续深入时看什么

把注意力放在上下文组织、可审查的改动和本地验证上。工具的功能与访问条件会变化，以对应官方页面为准。
