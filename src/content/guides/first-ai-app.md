## 先做最小的一条链路

对已有 TypeScript 或 Web 项目，可以从 Vercel AI SDK 的基础概念开始，了解模型调用与流式响应。需要组合模型、工具和 Agent 行为时，再看 LangChain.js 的官方示例。

## 按这个顺序阅读

1. 先了解 AI SDK 的基础概念和入门示例，区分模型调用与用户界面。
2. 想在电脑上运行模型时，阅读 Ollama 官方文档，核对本机条件和接入方式。
3. 需要自己的文档数据时，再研究 LlamaIndex 的数据与检索链路。
4. 需要联网资料时，查看 Tavily 的官方接入文档；需要统一多个模型服务时，再研究 LiteLLM。

## 一次只增加一种能力

聊天界面、数据检索、网页搜索与模型网关解决不同问题。先明确应用要完成的任务，再添加必要环节，而不是一开始就组合所有框架。

## 进入真实项目之前

结合所选服务的官方说明确认凭据配置、数据流向与错误处理。这里不提供可直接运行的教程代码，也不对模型输出效果作保证；相关资源帮助你找到具体实现的官方起点。
